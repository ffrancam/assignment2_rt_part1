Detailed Description

ROS action client for sending navigation goals and publishing the robot state.

Author
Francesca Magno
Version
1.0
Date
08/03/2025

Topics:

  • /robot_state: Publishes the robot's current state, including position (x, y) and velocity (vel_x, vel_<).
  • /target_topic: Publishes the target coordinates set by the user (x, y).

Topics:

  • /odom: Receives odometry data to update the robot's position and velocity in real time.

Clients :

  • /reaching_goal: Sends a goal containing the target coordinates (x, y) to the action server, which moves the robot to the destination.
